프로그램 우측 하단에 현재 실행 중인 버전을 표시합니다.

- 버전에 마우스를 올리면 ‘클릭하면 깃허브 릴리즈페이지로 연결됩니다.’ 안내가 표시됩니다.
- 버전을 클릭하면 GitHub 릴리스 페이지가 기본 브라우저에서 열립니다.
- ‘입력할 내용’을 직접 설정할 수 있습니다. 기본값 `1`은 예시이며 `Enter → 입력 내용 → Enter` 순서로 보냅니다.
- 개별 창 전환 안내를 고상 트레이더스 기준으로 명시했습니다.
- 시작 시 자동 업데이트와 기존 매크로·자동 중지·PC 종료 설정 동작은 유지됩니다.

기존 자동 업데이트 버전은 프로그램을 완전히 닫고 다시 실행하면 적용됩니다.
