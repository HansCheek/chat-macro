# 채팅 매크로

선택한 게임 클라이언트에 `Enter → 입력한 내용 → Enter`를 반복 입력하는 Windows용 도구입니다. 기본값 `1`은 예시이며 원하는 내용으로 바꿀 수 있습니다.

## 다운로드

[최신 실행 파일](https://github.com/HansCheek/chat-macro/releases/latest/download/ChatMacro.exe) · [릴리스 목록](https://github.com/HansCheek/chat-macro/releases)

`ChatMacro.exe` 하나에 아이콘과 실행에 필요한 파일이 포함되어 있습니다. Windows 10/11에서 실행하고 관리자 권한 확인을 허용하세요. 프로그램은 시작할 때 새 버전을 확인합니다.

## 사용법

1. 입력할 1·2·3클을 체크하고, 고상 트레이더스에 지정한 개별 창 전환 단축키와 맞춥니다.
2. 반복 간격을 초 단위로 지정합니다. 5·10·20·30분 버튼으로도 설정할 수 있습니다.
3. ‘입력할 내용’에 원하는 내용을 적고 시작합니다. 기본값 `1`은 예시입니다. 첫 입력도 설정한 반복 간격 뒤에 진행합니다.
4. 일시정지·계속·중지 버튼이나 `Ctrl + [`(시작), `Ctrl + ]`(중지)를 사용합니다.

자동 중지는 분 단위로 지정합니다. 일시정지 중에는 자동 중지 시간도 멈춥니다. **PC 종료는 기본으로 꺼져 있습니다.** 사용자가 `PC도 종료 (+5분)`를 체크했을 때만 자동 중지 5분 뒤 PC를 종료합니다. 종료 대기 중에는 취소 버튼을 사용할 수 있습니다. 저장하지 않은 작업은 미리 저장하세요.

입력은 현재 활성 창으로 전송됩니다. 게임이 외부 입력을 차단하거나 창 전환 단축키가 다른 경우 작동하지 않을 수 있습니다.
숫자는 기존 스캔코드 방식으로, 그 외 문자는 유니코드 방식으로 전송합니다. 문자 지원은 대상 게임에서 먼저 확인하세요.
프로그램 우측 하단의 버전에 마우스를 올리면 안내가 나오며, 클릭하면 GitHub 릴리스 페이지가 열립니다.

## 자동 업데이트

- 시작할 때 GitHub 최신 릴리스의 `update.json`을 확인합니다.
- 내장 공개 키로 업데이트 서명을 검사하고, 실행 파일의 SHA-256이 일치할 때만 새 버전을 실행합니다.
- 새 버전은 사용자의 로컬 앱 데이터에 보관합니다. 처음 다운로드한 실행 파일을 계속 눌러도 최신 확인된 버전이 실행됩니다.
- 인터넷 연결이나 업데이트 확인에 문제가 생기면 기존 버전을 실행합니다.
- 새 버전을 확인하는 동안 매크로 입력이나 PC 종료는 실행하지 않습니다.

## 유지보수

`packaging/version.json`의 버전을 올린 뒤 PowerShell에서 `packaging/build.ps1`을 실행합니다.

릴리스 태그는 `v1.1.0` 형식으로 만들고 `dist/ChatMacro.exe`, `dist/update.json`, `dist/SHA256.txt`, 버전별 ZIP을 함께 업로드합니다. **동일한 버전의 파일을 바꾸지 말고 새 버전을 만드세요.**

이 PC에서 GitHub 연결을 완료했다면 `packaging/publish.ps1`로 빌드·소스 업로드·릴리스 배포를 한 번에 진행할 수 있습니다. 모든 파일 업로드가 완료된 후 릴리스를 공개합니다.

업데이트 서명 개인 키는 `.release-secrets/update-signing-key.xml`에 보관하며 Git에 포함하지 않습니다. 이 키는 별도로 안전하게 백업하세요. 기존 프로그램에 업데이트를 배포하려면 같은 키를 계속 사용해야 합니다. Windows 코드 서명 인증서와는 별개의 업데이트 검증 키입니다.
