3클라 반복 매크로

다른 컴퓨터에서 사용하기
  배포용 ChatMacro.exe는 아이콘과 필수 파일을 모두 포함합니다.
  실행 파일 하나만 복사하거나 다운로드해 실행할 수 있습니다.
  ZIP으로 받았다면 압축을 풀고 EXE를 실행하세요.
  바로가기(.lnk), 실행.bat, assets 폴더를 별도로 복사할 필요가 없습니다.
  대상: Windows 10/11. 실행 시 Windows 관리자 권한 확인에서 '예'를 누릅니다.
  EXE는 로컬 앱 데이터에 실행용 파일을 잠시 풀고 종료 시 정리합니다.
  실행할 때 최신 릴리스를 확인하고 서명과 파일 검증을 통과한 새 버전이 있으면 적용합니다.
  인터넷 연결이 안 되면 기존 버전으로 실행합니다.
  GitHub 최신 릴리스: https://github.com/HansCheek/chat-macro/releases/latest

1. 고상 트레이더스의 개별 창 전환 단축키를 확인합니다.
   기본값: 1클 Ctrl + F10 / 2클 Ctrl + F11 / 3클 Shift + F11
2. 보라색 아이콘의 '채팅 매크로' 바로가기 또는 실행.bat를 더블클릭하고
   Windows 권한 확인 창에서 '예'를 누릅니다.
   자동으로 관리자 권한 실행을 요청하므로 우클릭할 필요가 없습니다.
   입력할 클라의 체크박스만 켜고 각 단축키를 고상 트레이더스과 같게 고릅니다.
   예: 1클과 3클만 체크하면 2클은 전환과 입력 모두 건너뜁니다.
   하나도 체크하지 않거나 선택한 클라의 단축키가 중복되면 시작하지 않습니다.
   매크로 창에서 반복 간격(초)을 설정합니다.
   29분 = 1740초. 기본 60초, 최대 86400초입니다.
   5분(300초), 10분(600초), 20분(1200초), 30분(1800초) 버튼을 누르면
   해당 초가 바로 적용됩니다. 초 직접 입력과 위아래 조절도 가능합니다.
   간격 변경은 매크로를 중지한 상태에서 가능합니다.
3. 시작을 누르면 최소화되고, 설정한 시간 뒤에 첫 실행을 시작합니다.

실행 순서
  아래는 기본 단축키와 예시 입력값 1로 세 클라를 모두 체크한 경우입니다.
  Ctrl+F10 → 1초 → Enter → 1 → Enter
  1초 → Ctrl+F11 → 1초 → Enter → 1 → Enter
  1초 → Shift+F11 → 1초 → Enter → 1 → Enter
  설정한 반복 시간만큼 대기 → 처음부터 반복

선택한 클라를 1→2→3 순서로 처리하며 체크하지 않은 클라는 건너뜁니다.
선택한 클라 처리가 모두 끝나면 완료 횟수가 1회 올라갑니다.
체크 여부와 단축키는 중지 상태에서 변경합니다.
각 키는 0.08초 누르고 떼며, Enter·1·Enter 사이에는 0.15초 기다립니다.
창 전환 단축키만 전송하며 실제 창 전환 성공 여부는 감지하지 않습니다.

시작 / Ctrl + [ : 새로 시작 (실행 중이면 그대로 유지)
일시정지 : 남은 시간, 클라이언트, 입력 진행 상태를 유지하며 멈춤
계속 : 해당 클라이언트로 다시 전환하고 최소 1초 기다린 뒤 이어서 실행
중지 / Ctrl + ] : 중지 (다시 시작하면 선택한 첫 클라부터 새로 실행)
X : 프로그램 완전히 종료

매크로 창에서 일시정지·계속·중지 버튼을 사용할 수 있습니다.
자동 중지 설정
  60분(1시간)·120분(2시간)·180분(3시간)·240분(4시간) 버튼을 누르면
  해당 분이 적용되고 자동 중지가 켜집니다.
  분 입력칸의 위아래 버튼으로 1~10,080분을 직접 설정할 수도 있습니다.
  '자동 중지: 켜짐' 버튼을 누르면 자동 중지를 끌 수 있습니다.
  시작 버튼을 누른 시점부터 사용 시간을 계산합니다.
  일시정지 중에는 자동 중지 시간도 멈추고, 계속을 누르면 이어서 계산합니다.
  설정 시간이 끝나면 반복 매크로만 중지하며 게임과 매크로 창은 닫지 않습니다.
  실행 중에는 설정을 변경할 수 없습니다. 중지한 뒤 설정하고 다시 시작하세요.
  다시 시작하면 자동 중지 시간을 처음부터 새로 계산합니다.
PC 자동 종료 (선택 사항)
  자동 중지를 켠 뒤 옆의 'PC도 종료 (+5분)'를 체크하고 시작합니다.
  예: 60분 설정 → 사용 시간 60분 후 매크로 중지 → 5분 뒤 PC 종료.
  일시정지 중에는 사용 시간도 멈춥니다. 종료 예약 전 수동 중지는 PC를 종료하지 않습니다.
  체크하지 않으면 기존처럼 매크로만 중지합니다.
  5분 대기 중에는 'PC 종료 예약 취소' 버튼으로 종료를 취소할 수 있습니다.
  Windows 종료 예약 후에는 매크로 창을 닫아도 종료 예약이 유지됩니다.
  창을 닫았다면 Win+R에서 shutdown /a를 실행해 예약을 취소할 수 있습니다.
  PC 종료 시 프로그램이 닫히므로 저장하지 않은 작업은 미리 저장하세요.
입력 시점에 매크로 창이 선택되어 있으면 잘못된 입력을 막기 위해 중지합니다.
처리 도중 다른 창을 클릭하면 그 창에 입력될 수 있습니다.
Windows 권한 확인을 취소하면 매크로를 실행하지 않습니다.
처음에는 반복 간격을 5초로 설정해 세 클라이언트에서 확인하세요.
게임이 외부 입력을 차단하면 작동하지 않을 수 있습니다.
추가 설치 없이 Windows PowerShell로 실행됩니다.

입력 내용과 버전 링크
  '입력할 내용'에서 Enter 사이에 전송할 내용을 직접 설정합니다.
  기본값 1은 예시입니다. 숫자나 원하는 한 줄 문구로 변경하세요.
  입력 내용 변경은 중지 상태에서 가능합니다.
  숫자 외 문자는 유니코드로 전송하므로 게임에서 지원되는지 먼저 확인하세요.
  우측 하단 버전에 마우스를 올리면 안내가 나오고 클릭하면 GitHub 릴리스 페이지가 열립니다.

작업표시줄 고정 (v1.1.2부터)
  기존에 PowerShell로 고정한 항목은 먼저 고정을 해제하세요.
  매크로를 완전히 닫고 다시 실행해 업데이트합니다.
  실행 중인 보라색 채팅 매크로 아이콘을 우클릭해 작업표시줄에 고정하세요.
  새 버전은 창을 ChatMacro.exe 자체에서 실행합니다.
